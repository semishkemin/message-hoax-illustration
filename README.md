Python-generated illustration recreating a late-1990s HIV needle urban legend message for a Semish Kemin essay.

# Message Hoax Illustration

Python code used to create an illustration for the Semish Kemin essay:

**“Welcome to the real world, you're HIV positive”**

The illustration recreates the visual language of a late-1990s forwarded message associated with the HIV needle urban legend discussed in the essay.

## Illustration
`output/message_hoax.png`
The illustration is generated in Python using Pillow.
The message text shown in the illustration is adapted from a version of the urban legend published in *The Austin Chronicle* in 1999.

## Source
Bartlett S. “About AIDS: An Urban Legend Re-Appears.” *The Austin Chronicle*. Published March 11, 1999. Accessed September 7, 2026.
https://www.austinchronicle.com/columns/about-aids-11732107/
